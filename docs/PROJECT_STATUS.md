## 2026-10-20 — Тормоза маршрута и переключения участников, пилюли шаблонов, значки в меню (UI-OWN-057/058)

Жалобы владельца: долгая загрузка маршрута «тренировка → упражнение → история → тренировка → назад» (вместо тренировки —

- **Причина тормозов — чтение «по одному запросу».** `readMesocycles` читал план по запросу на мезоцикл, неделю и упражнение;
  `listClientExecutions`/`listProgramExecutions` — пять запросов на каждое занятие. Замер (тест `training-read-cost`, счёт обращений
  к SQLite; программа 5 мезоциклов, 99 тренировок, 40 занятий): чтение плана **108 → 8** (малая программа — 8 и до, и после),
  чтение 40 занятий **121 → 5**. Пакетное чтение планов (5 запросов на всю программу клиента) и занятий; общая сборка
  `plannedWorkoutOf` (Map-ы вместо квадратичного filter).
- Кэш чтения `getPeriodizedPlan` (сбрасывается каждым `publish`; при чтении сверяется членство клиента — удаление клиента не
  оповещает план; поймано существующим тестом версий); справочник упражнений строится один раз (`exerciseLookup` в composition).
- **Назад из тренировки, открытой из истории/статистики:** «←» делал `popTo("TrainingProgram")`, а в новом рабочем пространстве экрана
  программы нет — он создавался заново и грузил весь план. Параметр `closeOnBack`: «←» закрывает клиента и возвращает на экран упражнения.

  программы/мезоцикла. Теперь: оповещение `selectionOnly` (экран его не перезагружает, выбор обновляется локально), данные нового
  участника ставятся одним обновлением, пока грузятся — прежние приглушены, позиция прокрутки запоминается при переключении и
  возвращается после отрисовки нового участника (страница короче при меньшем числе мезоциклов — упор в конец естественный).
- «Шаблоны»: четыре пилюли типа → `SegmentedControl compact`. Значки: меню шаблонов (`DropdownOption.icon`) и меню «⋮» конструктора

## 2026-10-18 — Конструктор без веса и отдыха, RIR, замена упражнения, порядок тренировок; колонки дневника

- Окно упражнения убрано совсем; вместо стрелки — «×» (убрать из тренировки) и «⇄» (заменить из каталога: новая
