# R04 — метрики упражнений 2.0 → 3.x

Статус: частичный dry-run mapping. Реальный импорт и восстановление не реализованы этим срезом.

## Входы и границы

- Задача R04, зависимость R03. Норматив: Product §§48.5.7, 49–50,
  Feature 08 и Feature 18 из пакета `FitCoach_3_DOCUMENTS_SYNCED_2026-10-14`.
- Уточнение владельца в текущей сессии: все упражнения 2.0 учитывают повторения
  и рабочий вес в килограммах; `20 × 10 кг` означает 20 повторений с весом 10 кг.
  Это основание для профиля `LOAD_REPS`, без определения смысла по названию.
- Имеющийся `LegacySetSourceReader.ts` читает отдельные текстовые колонки
  `training_session_sets.reps` и `training_session_sets.weight`.
  Формат надписи интерфейса не разбирается как источник данных.
- Целевой `SetValues` хранит вес в целых граммах. Смысл `null` и `0` различен.

## Реализованное соответствие

`LegacySetMetricCandidates.ts` строит кандидатов в памяти и включён в единый
read-only отчёт `npm run r04:full`. Приложение пока его не вызывает.

| Источник | Кандидат 3.x |
|---|---|
| Профиль 2.0 | `LOAD_REPS` |
| `reps = "20"` | `reps = 20` |
| `weight = "10"` | `loadGrams = 10000` |
| `weight = "2,125"` | `loadGrams = 2125` |
| Явный `weight = "0"` | `loadGrams = 0` |
| `null` / пустая строка | `null`, причина неполноты, исходная строка сохранена |
| Неразбираемое / отрицательное / неточное для целых граммов значение | `null` в кандидате, причина проверки и исходное значение сохранены |
| Время / расстояние отсутствуют | `null`; не вычисляются из других полей |

Перевод кг → граммы выполняется через целочисленную арифметику, без округления.
Проверяется диапазон безопасных целых чисел. Повторения должны быть целыми ≥ 1;
остальные формы остаются на проверке, а не удаляются. Повторения и вес проверяются
независимо: неполное поле не стирает другое корректное поле.

Кандидат сохраняет исходную строку с account/client/program/session/exercise,
physical row ID, source fact ID, сырыми метриками и lifecycle-маркерами.
Совпадение чисел не объединяет подходы разных клиентов, программ или сессий.
Корректные числа не доказывают выполнение подхода: сохраняется
`BLOCKED_PENDING_SEMANTIC_REVIEW`. ID целевых фактов и статусы выполнения
не назначаются. Наружу единый аудит возвращает только счётчики и фиксированные
коды причин, без имён, идентификаторов и значений тренировок.

## Новые характеристики упражнений

Оборудование, мышечная группа и профиль измерений — разные характеристики.
Профиль `LOAD_REPS` определён владельцем; из него нельзя вывести оборудование
или мышечную группу. Отсутствующие характеристики нельзя заполнять догадкой
по названию и нельзя автоматически сопоставлять упражнение с системным каталогом.

Оборудование уже nullable в текущей модели. Категория `bodyPart` обязательна;
у production-модели нет состояния «не уточнено». Поэтому завершённый перенос
собственных упражнений пока не доказан. Требуется отдельный staging-контракт
упражнения с сохранением source identity, названия, неизвестных характеристик
и ссылок из планов/истории; неизвестная категория не должна приводить к потере
истории. Feature 08 EX-06 требует явного ввода неизвестной категории при импорте
нового упражнения. Сценарий постепенного уточнения после обновления, предложенный
в разговоре, ещё предстоит реализовать и согласовать с этим правилом.
Текущий срез не ослабляет ограничения обычного создания упражнений.

## Проверки и открытые gates

- Синтетические тесты: направление `20 × 10 кг`, десятичная запятая, точный перевод
  дробного веса, ноль и пустота, некорректные числа, переполнение, сохранение
  происхождения/удаления/выполнения, изоляция владельцев и безопасный отчёт.
- Единый аудит проверяет новую секцию на файловой синтетической БД и сравнивает
  хеш источника до/после чтения.
- Реальная пользовательская база в этом срезе не открывалась.
- R04 остаётся PARTIAL: этот mapping охватывает метрики `training_session_sets`,
  но не доказывает полноту каталога, JSON set logs, сегментов, планов и архивов.
- R05 interrupted/low-disk, D03/D04 migration, D05 restore и Android gates OPEN.

Анкеты и их новая структура этим срезом не изменяются.
