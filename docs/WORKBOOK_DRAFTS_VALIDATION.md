# I07-WORKBOOK-DRAFTS — 2026-10-27

Реализован утверждённый план выбора нескольких листов, многократного открытия
сверки и управления черновиками. Исходная жалоба на зависание относилась к моменту
после открытия сверки; на подключённом устройстве она не воспроизводилась в этой
сессии, поскольку устройство не было доступно. Установка APK исключена владельцем.

Поведение:

- «Листы для импорта» хранит выбор независимо от вкладки. По умолчанию выбраны все
  непустые листы; пустые недоступны с пояснением. Снятие отметки сохраняет сверку,
  исправления, ввод спорных значений, неделю и настройки листа. Проверки относятся
  только к отмеченным листам. Перед подтверждением видны программа, имена листов
  и количество добавляемых циклов.
- Один host Modal содержит подготовку, историю сопоставлений, выбор листов, сверку
  и подтверждение. Удалено одновременное открытие двух native Modal при запуске.
  Монтируется только текущая сверка. Подготовка уступает управление между листами;
  отмена инвалидирует поздние ответы. Опциональную историю можно пропустить.
- Запуск имеет синхронную защиту от повторного нажатия. Запись не освобождает блокировку
  до фактического завершения транзакции. Ошибка записи оставляет подтверждение для
  повтора; отмена выбора файла и закрытие не оставляют заблокированный экран.
- В расширенном конструкторе импорт добавляет циклы в текущий черновик. Пустой
  стартовый заменяется; заполненный и его настройки сохраняются. Переключатель
  сохраняет текущие правки, неделю и сырое значение диапазона повторений каждого цикла.
- Импорт в новом простом конструкторе предлагает переход в расширенный: текущий
  план сохраняется отдельным циклом. Существующий расширенный черновик не затирается:
  переход блокируется с пояснением, пока владелец его не продолжит или не удалит.
- Общая запись черновика публикует программу, циклы, выполнения, новые сопоставления,
  квитанции и удаление recovery-черновика одной транзакцией. Для импортированных
  слотов устанавливается COMPLETED, не придумываются факты, даты и время.
- Копии планов другим клиентам не содержат чужих результатов. При размещении в новой
  программе участника все циклы попадают в одну его программу. При правке сохранённого
  цикла остаётся защита результатов: без выбора KEEP_HISTORY/DELETE запись отклоняется.
- Квитанции по листу и целевой программе предотвращают дубли между прямым импортом
  и последующим импортом в конструкторе. Изменённый сохранённый цикл вызывает конфликт.
  Старые программы и квитанции не переписываются автоматически.
- Выход предлагает сохранение, удаление или продолжение редактирования. Очередь
  автосохранения дожидается текущей записи и отменяет ожидающие перед удалением;
  unmount не восстанавливает удалённую работу. Ошибка удаления сохраняет последнюю
  ожидающую версию для повторного сохранения. Аварийное автосохранение остаётся.
- «Создать программу» предлагает продолжить найденный черновик или начать новую.
  Черновики простого и расширенного типов показаны раздельно. Удаление старого
  черновика выбранного типа требует подтверждения. Список обновляется при возврате.

Контракты: явный WorkbookImportTarget, selectedSheetIds в WorkbookReviewSession,
общие data-only BuilderWorkbookState/BuilderWorkbookSaveRequest и транзакционный
saveBuilderWorkbook. JSON остаётся в существующих таблицах recovery; старые
одиночные черновики поддерживаются. Plans v4 обновляет JSON-guards, transfer v3
добавляет nullable cycle_id квитанции. Новых постоянных таблиц нет.

  импортов с историческими сопоставлениями и без них, отмену, поздний ответ,

  Это host-тест React, он не проверяет Android window focus и физические жесты.

  Ошибка второго цикла откатывает всё, включая сопоставления; recovery остаётся.
