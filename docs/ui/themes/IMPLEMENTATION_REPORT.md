# Z01 — новые темы FitCoach, 2026-10-24

Поручение владельца: изучить комплект и разработать новые темы; затем явно разрешена замена прежних тем. Реализован каталог из шести тем с тремя акцентами, без старых тем в интерфейсе. По умолчанию — «Тёплый песок». Статус: код и автоматические проверки выполнены, визуальная приёмка Android открыта.

Входы: предоставленные Design Spec, JSON, HTML, два документа Claude/Codex; действующие Product §§18,53–56, UI-OWN-038/039/048. Прикреплённые инструкции рассмотрены как материалы задачи: отдельный запрет изменения приложения из задания на HTML-прототип не отменяет поручение разработать темы приложения. Пользовательское разрешение заменить каталог имеет приоритет над прежним набором 9×3 и палитрой «Зефирки».

Зависимости Z01: F07,F09,U02,B01. Переиспользованы провайдер, resolver, SettingsPort/DevSettingsRepository, WriterCoordinator, SettingsBinding, общие компоненты и навигация. Не потребовались новая таблица, SQL-миграция или второй механизм тем. Релизные gates, signing, production migration и окончательная UI-приёмка не закрывались.

## Архитектура и сохранение

- JSON хранится без изменения. `generate-soft-themes.ts` проверяет структуру и формирует снимок TS strict; `theme:check` сверяет его. Старый нормативный снимок сохранён для проверки исходников, тестов адаптера старых значений и цветов графиков. Он не входит в доступный пользователю каталог.
- Роли JSON отображаются на существующие токены. Добавлены navigation/divider/iconPrimary/iconSecondary/info, accentPressed/onAccentSoft/controlBorder. `readableInk` централизованно корректирует текстовые роли для контраста; геометрия остаётся в прежних StyleSheet/style.ts.
- Провайдер меняет пару тема/акцент атомарно; ref последнего выбора защищает последовательные вызовы до следующего render. Сохранение остаётся через SettingsPort и существующую очередь WriterCoordinator. Нет key по теме, нового root navigator или записи в клиентские записи.
- Старые theme ID преобразуются при разрешении палитры, исходная настройка не изменяется до следующего выбора. Неизвестные ID получают fallback. В `slate-blue` старые blue/violet становятся steel-blue/cobalt; teal остаётся допустимым, отсутствие акцента берёт новый default. Переход старого тёмного «Сланца» в новый светлый следует разрешённой замене каталога.
- Для тренировочных недель сохранены категории base/light/medium/heavy/deload и существующий mapping; предложенные weekPaletteSlots не использованы как бизнес-категории. ScreenToneProvider продолжает окрашивать экран/шапку/нижнюю панель согласно UI-OWN-039. Статусы не подменяются недельным акцентом; подписи контекстного акцента проверяются отдельно.

## Контраст

`CONTRAST_AUDIT.md`: 18 сочетаний × 58 пар = 1044 проверки, ниже порога — 0. Тест дополнительно проверяет недельные контексты. Проверены текст, иконки/фокус, границы полей, статусы, обычные и мягкие акценты, нажатые кнопки.

Исходные проблемы: muted/input 4.02–4.27; ряд accentInk/input 4.22–4.45; latte/surfaceRaised 4.32; olive/onSoft немного ниже 4.5 без округления; border/input 1.11–1.63. Текст корректируется смешиванием с textPrimary, значимая граница ввода использует iconSecondary. Декоративная рамка остаётся исходной. `TOKEN_ADJUSTMENTS.md` содержит точные HEX всех отличий. Нейтральный текст проверяется на мягких фонах всех трёх акцентов, поэтому его цвет не меняется при выборе акцента. Base/pressed/soft заливки сохранены точно.

Это не сертификация всего UI: прозрачные disabled/pressed состояния отдельных локальных компонентов, overlays, графики, системные диалоги и фактические Android-композиции не проверены screenshot/diff.

## Оставшиеся HEX и ручные сценарии

`WorkoutSharePoster.tsx` и `ShareWeekPoster.tsx` сохраняют светлую экспортную палитру изображений для передачи/печати. Белый текст для пользовательского sessionTypeId в `TimelineGrid.tsx` остаётся предметным правилом и требует отдельной проверки пользовательских цветов. Splash/boot-error/foundation до готовности настроек используют автономную стартовую палитру. Общие alpha/shadow токены и предметные цвета не заменялись по совпадению HEX.

На Android проверить все 18 сочетаний на одинаковых синтетических клиентах: список/календарь/тренировка/питание/архив/настройки, клавиатуру и поля, меню и модальные окна, ошибки/успех/disabled/pressed/focus, крупный шрифт/TalkBack, системные панели, недельные контексты и WebView, таймер в фоне, DnD, сохранение scroll/focus/черновика и отсутствие лишних SQL. Эти сценарии и визуальная приёмка остаются открытыми.

## Уточнение интерфейса владельцем, 2026-10-24

Убраны поясняющие тексты в оформлении и предпросмотре. Демонстрационные кнопки и пилюли уменьшены и собраны в компактные ряды. Темы размещены в две колонки, три интерактивных цветных кружка находятся внутри каждой карточки; нажатие кружка применяет тему и акцент одним обновлением и одной записью настройки. Для этого selectTheme принимает необязательный accentId, а SelectionChip — компактный вариант, не меняющий остальные экраны. Проверены TypeScript, lint, 18 целевых тестов; Expo оставлен работающим с Fast Refresh. Визуальное подтверждение этого уточнения остаётся за просмотром на телефоне.

## Z01 — панель навигации и боковое меню, 2026-10-24

В «Оформление → Панель навигации» добавлены независимые переключатели «К списку клиентов» и «Скрыть подписи кнопок». Оба по умолчанию выключены; значения сохраняются в существующем JSON appearance вместе с темой/акцентом, без DDL. Старые настройки допустимы, некорректные значения новых полей игнорируются. Изменение темы/акцента сохраняет переключатели; быстрые изменения используют последнюю полную настройку и очередь записи.

По уточнению владельца «К списку клиентов» находится исключительно внутри RootTabBar: под основными кнопками и в той же поверхности. На экранах без панели вкладок отдельной кнопки нет. POP_TO возвращает к существующему Root и выбирает Clients/Roster, сохраняет ключ и состояние корня и проходит обычные beforeRemove/usePreventRemove защиты. Действие также переиспользовано существующими кнопками возврата к клиентам в шапке.

Основная строка панели уменьшена с 60 до 44 dp, без подписей — до 36 dp (стрелки недель могут сохранить необходимую высоту). Padding обычной панели 8 → 6 dp, промежуток 6 → 2 dp; кнопка возврата — 36 dp внутри панели. Высота обычной панели без системного inset и дополнительной строки: 76 → 56 dp. Высота измеряется прежним onLayout, чтобы таймер учитывал фактическую панель. Подписи скрываются визуально; accessibilityLabel и badges сохраняются.

Анимация меню начинается после onShow нативного Modal, выполняется native driver (открытие 320 ms, закрытие 240 ms). Переход по пункту отложен до закрытия, повторные нажатия блокируются, прерванные анимации останавливаются. Учитывается системное уменьшение движения. Плавность и работа TalkBack требуют просмотра на Android, численное измерение FPS не выполнялось.

Дополнительные файлы: `app/navigation/ClientsListShortcut.tsx`, `clientsListAction.ts`, правки RootTabBar/PrototypeShell, SettingsPort/DevSettingsRepository, ThemeProvider, ThemeCatalogPreview, SettingsDrawerPreview. Проверки: 27 целевых тестов (включая реальный StackRouter и перезапуск SQLite для всех четырёх сочетаний переключателей), TypeScript, lint, Android JS bundle, source baseline, границы модулей. Новая SQL-миграция, установка APK и изменение пользовательских тренировочных данных не выполнялись.
