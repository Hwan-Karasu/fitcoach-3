Если потребуется обязательное фото/3 ингредиента/3 шага — уточнить противоречие, не ужесточать молча.
- D01 production DDL, миграция build120, backup/restore, UI-gates остаются OPEN. Внешних пищевых баз, облачных сборок, платных сервисов нет.

Переиспользованы существующие порты, repositories, снимки, planBatch/recipeBases, dev migration ledger, ConfirmDialog, темы и навигация. Новые изменения **ещё не приняты по Android**:
