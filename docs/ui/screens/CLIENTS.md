# Экран «Клиенты» — спецификация (эталон)

Статус: собран и проверен на телефоне 2026-10-17 по макету владельца (UI-OWN-017):
«Сегодня по расписанию», 3 показателя и индикатор ограничений работают. «Все клиенты ▾»
пока содержит только «Все клиенты» — пол и метки появятся с полями карточки.
Проверен в «Полярной»; остальные темы и golden — впереди. Общие правила — [UI_STYLE_DECISIONS.md](../UI_STYLE_DECISIONS.md).
Содержание экрана — Product §7, Atlas «Клиенты».

## Компоновка сверху вниз

1. **Шапка** (UI-OWN-001/002/016): вверху значок и «Дневник атлета», при прокрутке —
   «Клиенты»; справа колокольчик и меню.
   Счётчика «24 активных клиента» нет — он на бейдже вкладки.
2. **Поиск** во всю ширину (радиус 10). Отдельной кнопки фильтров нет — её роль
   у «Все клиенты ▾» (макет владельца).
3. **Ряд фильтров** на всю ширину, радиус 8, доли 1 / 1.4 / 1: «Сегодня» со значком
   календаря, «Все клиенты ▾», сортировка «Имя А–Я ▾» (при «Сегодня» — «Время»).
4. **«Создать карточку клиента»** — плавающая квадратная «+» справа внизу (UI-OWN-017).
5. **Разделы списка:** «Дни рождения», «Недавно открывали», «Все клиенты».
   Название слева, счётчик справа, разделы не сворачиваются; «Дни рождения» —
   акцентным цветом. При «Сегодня» — один раздел «Сегодня по расписанию».
6. **Нижняя навигация** — Клиенты / Календарь / Архив (UI-OWN-004), на «Клиентах»
   бейдж с числом активных.

«Обратной связи» на экране нет — она в боковом меню (UI-OWN-006).

## Карточка клиента в списке

- Тонкая рамка 1px без тени, радиус 12, отступ между карточками 8.
- **Аватар** — квадрат 44dp (радиус 8) с эмодзи или инициалами
  на тонированном фоне. Нажатие на аватар — быстрая смена эмодзи (§7.8).
- **Имя**, под ним строка «34 года · Есть ограничения» — бейдж ограничений
  маленькой плашкой предупреждающего цвета под именем.
- **Показатели** — нижняя строка карточки, значок + значение без подписей (подпись
  читает TalkBack): следующее занятие («Сегодня 14:00»), последняя тренировка («—» до
  дневника T03), абонемент («8 зан.», «Без учёта», «Нет пакета»). Набор — §7.7.
- **Ограничения** — признак из раздела анкеты «Здоровье»: «Противопоказаний нет:
  Нет» или заполненные поля о диагнозах, травмах, операциях, боли. Текст не
  показывается.
- Справа — стрелка «›». Кнопки «Изменить» на карточке нет: нажатие открывает
  карточку клиента, правка — изнутри.
- **Особые карточки** (день рождения, ограничения) — акцентная полоса слева
  и янтарный бейдж со значком справа («ДР через 3 д.»).

## Состояния

| Состояние | Вид |
|---|---|
| Клиентов нет | «Клиентов пока нет» + «Создать карточку клиента» |
| Ничего не найдено | «Ничего не найдено» + «Сбросить фильтры» |
| «Сегодня» без записей | короткий текст + «Все клиенты» |
| Загрузка | скелет: 3 карточки-заглушки той же формы |

## Приёмка

- Скриншоты во всех темах каталога (UI-OWN-015), длинное имя, font scale,
  TalkBack (аватар, бейджи, стрелка), клавиатура поверх списка при поиске.
- После утверждения — golden в `docs/ui/goldens/clients/` и статус в
  `SCREEN_APPROVAL_MATRIX`.
