# Возврат из редактора мезоцикла

Область: UI-OWN-040/041, существующий экран программы и редактор мезоцикла. Зависимости: React Navigation focus, native stack, react-native-sortables; данные через TrainingPlansRepositoryPort. DDL и release gates не затрагиваются.

При возврате фокуса книга мезоциклов пересоздаёт Sortable.Flex, чтобы повторить нативное измерение карточек после отсоединения экрана навигацией. Внешний ScrollView остаётся смонтированным. Обычные перерисовки и перетаскивание не пересоздают список. Неполный порядок, дубликаты и неизвестные идентификаторы от сортировки отклоняются до оптимистичного обновления и записи.

Проверено на подключённом Android: существующая программа с двумя мезоциклами → «Изменить» → «Отмена», затем повторно → стрелка назад. В обоих случаях карточки видны без смены участника. Реальные планы не сохранялись и не удалялись. Возврат после сохранения на телефоне отдельно не проверялся; сохранение покрывается существующими тестами редактора.

11 targeted tests (training-state-hooks, training-program-scroll, training-mesocycle-edit), mobile TypeScript, targeted ESLint и module boundaries прошли.

Запуск Expo Go восстановлен повторным подключением к Metro через USB reverse и холодным открытием приложения без очистки данных. Рабочие экраны подтверждены на телефоне. Точная причина исходного падения не установлена; восстановленный запуск не является доказательством устранения всех причин падения.
