## Поведение

Системная заставка и React-анимация разделены. `preventAutoHideAsync` вызывается до импорта дерева приложения. Нативная заставка скрывается после layout React-корня и следующего frame callback. Фон обеих заставок — `#00171C`; стандартное дополнительное нативное исчезновение за 400 мс отключено. Прозрачный Android vector drawable исключает подстановку квадратной иконки запуска.

Шрифты загружаются одновременно с bootstrap. Заставка использует системный полужирный шрифт и может отображаться до их загрузки. Основные экраны получают репозитории после прежней проверки БД; открытие дополнительно ждёт шрифты либо их явную ошибку, `NavigationContainer.onReady` и frame callback.

**Минимального таймера показа больше нет.** Когда интерфейс готов, начинается исчезновение за 180 мс, независимо от положения декоративной анимации и декодирования её PNG. При reduced motion исчезновение мгновенное. Длительность 2000 мс относится только к полному визуальному сценарию, если загрузка действительно продолжается.

Если загрузка длится дольше, фигура остаётся собранной. Повторного проигрывания нет. Возврат из фона показывает окончательное состояние; незавершённое исчезновение отменяется при уходе в фон. Размонтирование отменяет анимации и подписку AppState. Ошибка bootstrap открывает прежний экран с повтором; retry не возвращает заставку.

Автокопирование, сверка уведомлений, очередь диалогов исходов занятий и обработчик открытия уведомлений монтируются/активируются после исчезновения заставки. Последний по-прежнему читает сохранённое стартовое уведомление. Сам контейнер навигации при завершении заставки не перемонтируется.

## Графика и движение

GIF содержит 9 кадров и используется только как референс. В runtime он не воспроизводится и не включён в ресурсы.

Исходная PNG эмблемы размером 1254×1254 с прозрачным фоном сохраняет металлическую фактуру, силуэт и пропорции. Один SVG Image раскрывается через alpha-маску с 32 отдельными геометрическими гранями. До 450 мс появляются слабые контуры, между 450 и 1050 мс последовательно раскрываются грани и соединяющие тёмные поверхности.

Отблеск между 1050 и 1650 мс задаётся отдельной временной функцией для каждой грани: время отражения зависит от её положения, яркость и направление градиента — от ориентации поверхности. Небольшие точечные вспышки привязаны к острым граням. Нет прямоугольной полосы света поверх всей картинки. Бирюзовые фоновые переливы — статические SVG-градиенты, без blur.

Параметры обновляет один shared clock Reanimated на UI thread. На кадрах не вызывается React setState; React обновляет только этапы жизненного цикла. Нет масштабирования всей фигуры, внешней рамки, полоски под названием, индикатора процентов или дополнительных надписей.

## Диагностика исходных пяти секунд

Анализ кода выявил последовательность:

1. `App` возвращал `null` до окончания загрузки четырёх шрифтов. Runtime/SQLite начинали запускаться лишь после этого.
2. Production bootstrap проверяет незавершённое восстановление и совместимость локальной SQLite, выполняет необходимые миграции.
3. Затем последовательно инициализируются 16 владельцев хранилищ. Их initialize повторно проверяет собственные migration ledgers; это не полная загрузка истории всех разделов.
4. До APP_READY восстанавливаются таймеры и согласуются их системные сигналы. Этот этап включает обращения к модулю уведомлений и ОС.
5. После APP_READY повторно читается оформление в SettingsBinding, монтируется навигация и читаются данные первого экрана. Прежняя заставка проверяла APP_READY, но не фактическую готовность этого дерева.
6. Ранее заставка отдельно удерживалась минимум 750 мс. Теперь фиксированное минимальное ожидание удалено.

Сетевого входа пользователя, восстановления серверной сессии или облачной синхронизации в этом offline V1 нет. Проверки recovery/совместимости SQLite и восстановление таймеров сохранены. Порядок 16 владельцев не распараллеливался: у схем есть зависимости, а единственный writer сериализует транзакции.

Выполненные оптимизации: параллельная загрузка шрифтов и bootstrap; отсутствие обязательной длительности заставки; отложенный запуск автокопирования и сверки уведомлений; отсутствие дополнительного нативного fade; вычисление кадров без React-рендеров.

**Первопричина именно пяти секунд пока не измерена.** Число модулей в bundle и количество initialize не доказывают время на телефоне. Не заявляется ни двухсекундный запуск, ни достижение 60 FPS.

## Трассировка и фактически выполненные проверки

Добавлен `StartupDiagnostics`: максимум 32 числовые записи, без SQL, путей, идентификаторов клиентов или данных здоровья. После закрытия заставки одна запись `[startup]` содержит точки JS entry, React layout, скрытие native splash, готовность шрифтов/навигации и длительности recovery, подготовки БД, initialize репозиториев, восстановления таймеров и чтения темы.

Начало этой трассы относится к выполнению JS-модуля. Она не включает создание Android-процесса, не измеряет render FPS и не заменяет TTID/TTFD из Android Macrobenchmark/Perfetto.

Первый общий прогон в песочнице остановился на 39 тестах с `spawnSync EPERM`. Повтор с разрешённым запуском дочерних процессов прошёл полностью; код этих тестов не изменялся.

Тесты специально проверяют: быстрый переход до декодирования PNG и без минимального таймера; ожидание БД/шрифтов/навигации; ошибку и retry без нового intro; отложенные notifications без перемонтирования детей; отмену при background, возвращение без replay, reduced motion и освобождение подписок/анимаций. Unit-выборки временной функции при шаге 1/60 с проверяют её непрерывность, но не измеряют FPS.

На момент проверки `adb devices` показывает `Ucamera001 offline`. Поэтому не измерены: cold/warm launch, TTID/TTFD, p50/p95, пропуски кадров, память и 60 FPS на устройстве среднего класса. Не проверены Android-пиксели перехода, safe area/system bars, реальный TalkBack и доставка стартового уведомления. Новый APK не собирался; изменения native plugin требуют новой нативной сборки.
