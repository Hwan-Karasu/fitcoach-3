# План реализации UI-концепта «в духе Onlyfits» (2026-11-09)

Источник: макет [concepts/ONLYFITS_CONCEPT_2026-11-09.html](concepts/ONLYFITS_CONCEPT_2026-11-09.html), решения
UI-OWN-059…085 в [UI_STYLE_DECISIONS.md](UI_STYLE_DECISIONS.md), ADR-059 (Health Connect) в `memory-bank/decisions.md`.
Задачи — [UIX_BACKLOG.json](UIX_BACKLOG.json). Все решения `PROPOSED`, код не менялся, на телефоне не проверено.

Решения владельца по плану: Health Connect — **в V1 наравне** с остальным (после gate, этап 5); порядок — **сначала общие
компоненты, потом экраны**. Правила проекта действуют полностью: одна задача — один срез, слои и `public.ts`, запись через
`WriterCoordinator`, новая таблица — миграция в журнале владельца, факты не уничтожаются, цвета только из темы, Manrope,
lucide, hit-area ≥ 48 dp, новые библиотеки — только с согласия владельца через `npx expo install`.

Обозначения: **UI** — вид; **UX** — поведение; **Логика** — данные и правила (**новое** — того ещё нет в коде);
**Файлы** — основные места правки (пути от `apps/mobile/src/`); **Тест** — что проверить автоматически.

## Решения владельца (2026-11-09)
1. Абонемент «кончается» — осталось **3 занятия и меньше** (UIX-02).
2. «−30 / +30» в окне записи **остаются** (UIX-04).
3. «Анкета заполнена на N %» — **по всем вопросам** анкеты (UIX-10).
4. Рисунки процента жира — **собственные** (перерисованы по результату ChatGPT); вопрос прав закрыт (UIX-06).
5. Вес — **ручной ввод главнее**; шаги — **считает Health Connect** (UIX-16).
6. «Сохранить» в «Списке и карточках клиентов» **убирается** — сохранение сразу (UIX-13); поля упражнения в конструкторе — **в одну строку** (UIX-14).
7. Рекомендацию сна 7–9 ч **проверить по источнику** перед реализацией; цель по умолчанию 8 ч (UIX-05).
8. **Согласие на библиотеку (Health Connect для Expo SDK 57) дано**; установка — только через `npx expo install` совместимой версии (UIX-15).
9. Подтверждения при закрытии окна записи **нет** (UIX-04).
10. Рисунки: приводятся к одному размеру, диапазоны ориентировочные, метод «оценка по рисунку» (UIX-06).
11. Сон: цель 8 ч, подпись «не менее 7 ч для взрослых» (UIX-05).
12. Распространение — **APK «для своих»**, не Google Play; декларация и публичная политика отложены (UIX-18 отменена), заготовка сохранена.
