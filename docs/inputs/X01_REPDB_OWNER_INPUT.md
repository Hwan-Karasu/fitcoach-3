# X01 — вход владельца: бесплатный RepDB и русский язык

**Статус: запланированный вход, не интегрировано.** Владелец попросил
использовать бесплатный каталог упражнений RepDB и самостоятельно подготовить
русский язык. Это не означает, что X01, лицензирование и контентная проверка
уже завершены.

Официальный источник: <https://github.com/RepDB/exercise-dataset>.
Лицензия данных: <https://github.com/RepDB/exercise-dataset/blob/main/LICENSE-DATA.md>.
Бесплатная редакция разрешает использование данных и изображений внутри
приложения при видимой атрибуции, но запрещает перепубликацию как отдельного
датасета/API; платные preview-материалы не предназначены для production.
Перед загрузкой зафиксировать конкретный commit, состав файлов, SHA-256 и
актуальные условия. Не помещать скачанный набор в публичный репозиторий,
пока не проверен допустимый способ поставки приложения.

В исходном каталоге заявлены EN/DE/ES, не RU. Русские названия, синонимы и
инструкции должны жить отдельным проверяемым слоем поверх стабильных ID
RepDB: смена текста не должна менять exercise identity, план или историю.
Техника движения и медицински чувствительные формулировки требуют редакторской
проверки; автоматический черновик перевода сам по себе не считается готовым
русским контентом. Сопоставление с legacy-упражнениями — только после
проверки aliases и происхождения, без автоматического fan-out.

Работа относится к `X01` после D01/F05. Каталог пока не скачан и не встроен.
