# I04-IMPORT-CATALOG — 2026-10-26

Реализован утверждённый план каталога и сопоставлений при импорте.

- Окно импорта перед обработкой возврата обращается к каталогу через CatalogBackHandle.
  Открытый фильтр закрывается первым, затем возврат переводит в сверку. Экранная
  стрелка и Android Modal.onRequestClose используют одну последовательность.
- В фильтре и редакторе упражнения добавлен поиск по уже существующему оборудованию.
  Варианты не скрываются по мышцам, режиму или поиску упражнений. Нулевое количество
  не делает плитку недоступной. «Бабочка» находит существующий pec_deck; новые
  записи оборудования, категории и изображения не добавлялись.
- Сопоставления книги хранятся по точному исходному названию после trim. Регистр,
  «е/ё», пунктуация и внутренние пробелы различаются. Ручной выбор и созданное
  упражнение распространяются на все совпадения, включая неоткрытые листы.
  Нормализованные ключи старого адаптера различаются при буквальных коллизиях;
  обычные прежние ключи сохранены. Сохранённые тренировочные записи не переименовываются.
- Прошлые сопоставления предлагаются общим списком. До подтверждения они не
  подставляются, в том числе через автоматическое совпадение каталога. Частично
  подтверждённые пары применяются только к выбранным названиям. Недоступные цели
  требуют нового ручного выбора; текущий ручной выбор приоритетнее истории.
- Пары сохраняются после успешного импорта или применения плана к черновику.
  В полном импорте новые пары и тренировочные записи коммитятся одной транзакцией.

Интерфейсы: ExerciseImportMatchesPort, CatalogBackHandle, общие сопоставления
WorkbookReviewSession. Владелец training-transfer получает миграцию v2 с таблицей
training_import_exercise_matches: рабочее пространство, точное название с BINARY
сравнением, ID каталога. Память общая для клиентов тренера. Она включается в полный
`.atbackup` и не экспортируется в Excel.
