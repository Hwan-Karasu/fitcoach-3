# I05-WHOLE-WORKBOOK — 2026-10-26

Уточнение владельца: книга — одна программа, лист — цикл. Прежняя область импорта
«открытый лист» отменена для полного импорта из карточки клиента.

Реализовано:

- Все листы разбираются при открытии книги; вкладки управляют сверкой, а не областью
  сохранения. Ранее открытые вкладки сохраняют локальное состояние просмотра.
- «Импортировать всю книгу» собирает одну расширенную программу с циклами в порядке
  Excel. Название берётся из имени файла и доступно для изменения.
- Проверяются все непустые листы: сопоставления, настройки столбцов, спорные значения
  и даты. Список проблем позволяет перейти к нужному листу. Непустой непрочитанный
  лист не пропускается. Пустые листы явно перечисляются как пропущенные.
- Программа, планы, результаты и новые ручные сопоставления записываются существующей
  транзакцией владельцев. Ошибка не оставляет частично импортированную книгу.
- Временные ключи включают книгу, лист и неделю, затем преобразуются в новые ID
  владельцем. Это различает одинаковые тренировки, даты и повторяемые простые планы.
  Хеширование ограничивает длину ключей больших книг; повторная загрузка стабильна.
- Сохранённые ранее частичные импорты не изменяются. Восстановление прошлой сверки
  не выполняется по просьбе владельца. Новая миграция БД не требуется.
- Загрузка плана в уже открытый черновик одного цикла остаётся отдельным действием
  с явно указанным выбранным листом. Полный импорт книги доступен в карточке клиента.
