# I06-IMPORT-COMPLETION-RENAME — 2026-10-26

Владелец подтвердил: завершать все тренировки всех циклов импортируемой книги,
сохраняя пустые подходы пустыми. Дополнительно запросил переименование самой программы.

Результат:

- Полный импорт книги устанавливает COMPLETED для каждого планового слота. Если
  в исходнике нет фактов тренировки, создаётся завершённое выполнение без фактов.
- Подходы, подтверждения, повторы, вес и другие показатели не дополняются выдуманными
  значениями. Время начала/окончания не подменяется временем импорта.
- Неизвестная дата сохраняется как NULL; известные даты сохраняются и проходят прежнюю
  проверку формата. Предварительный просмотр сообщает о неизвестных датах и допускает импорт.
- Все циклы, выполнения и сопоставления сохраняются одной транзакцией; повторный
  идентичный импорт не создаёт дублей. Прежние сохранённые программы не переписываются.
- В «…» карточки программы доступно «Переименовать программу» с вводом до 80 символов,
  сохранением и отменой. Используется существующая команда renameProgram и её проверка
  ревизии. Пункт внутри программы также уточнён; названия циклов не меняются.

Миграция execution v3 меняет только допустимость NULL в actual_date. Транзакционно
копируется и пересоздаётся дерево собственных таблиц execution с включёнными FK;
возвращаются прежние индексы и защитные триггеры. Базовая миграция v1 не изменяется.
Новые постоянные таблицы не добавляются; все ID и значения строк сохраняются.
