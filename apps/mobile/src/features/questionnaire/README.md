# Questionnaire

Схемы, черновики и опубликованные ревизии, условные поля и ответы по stable
field ID. Скрытие/редакция вопроса не перезаписывает исторические ответы.

Dev-only вертикальный срез Q01 (`data/DevQuestionnaireRepository.ts`) живёт в
общем dev-файле с Clients, журнал миграций `questionnaire_schema_migrations`.

- Единая модель поля (§23.1) для системных и своих вопросов; 7 типов §23.5;
  варианты выбора со стабильными ID (§23.15); условие видимости
  «поле / равно · не равно · содержит / значение» (§23.8).
- Проверка ответа: тип вопроса и ограничения поля (`FieldConstraints`:
  число — минимум/максимум/целое, текст — длина, дата — не в будущем / не
  раньше); сообщения на русском под самим вопросом.
- Стандартная анкета — версия 1 (`sys:` ID, разделы §10.4). Опубликованные
  версии неизменяемы (триггеры), один черновик с CAS по revision, публикация
  атомарна: проверка схемы (циклы, сломанные ссылки, ограничения), запрет
  публиковать без изменений и с устаревшей базой, ответы на опубликованные
  вопросы нельзя потерять (только скрыть или убрать из анкеты).
- Ответы — отдельная таблица по `field_id`, а не поля карточки клиента;
  заполненность NOT_STARTED / IN_PROGRESS / COMPLETE считается только по
  применимым обязательным вопросам (§10.3).
- `QuestionnaireForm` — общий отрисовщик для анкеты клиента и будущего
  предпросмотра конструктора; `ClientQuestionnaireScreen` в «Ещё → Анкета».

Не реализовано: конструктор анкеты, предпросмотр, история версий в UI (Q02),
undo/redo, перенос анкет build120.
