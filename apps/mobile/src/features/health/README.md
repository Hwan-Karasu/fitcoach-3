# Health

Health Connect (ADR-059, ADR-061): чтение шагов, сна, общего и активного расхода, веса и % жира для **одной** карточки «для себя».

- `domain/` — виды данных, привязка, порты (`HealthStorePort`, `HealthConnectPort`), правила разбора по локальным дням (сон — по дате пробуждения).
- `data/` — схема владельца (`health_link`, `health_daily`), хранилище, участник окончательного удаления клиента, адаптер к системе (`react-native-health-connect`).
- `presentation/` — раздел «Health Connect» в карточке клиента и хуки чтения.
- Перенос в Nutrition и Measurements — `workflows/syncHealthConnect.ts`: ручной ввод главнее, шаги — из Health Connect.

Только чтение: приложение ничего не записывает в Health Connect и ничего не читает в фоне. Отключение снимает привязку и доступ, записанные дни остаются.
Адаптер к системе проверяется только на устройстве (APK); всё остальное покрыто тестами `health-rules` и `health-sync`.
