# Calendar

Appointments, duty/blocked slots и расписание. Не создаёт Workout Session;
финансовые эффекты проходят через явный workflow с Accounting.

Dev-only вертикальный срез K01 (`data/DevCalendarRepository.ts`) хранит данные
в общем dev-файле с Clients (`shared/db/SharedSqliteDatabase.ts`), со своим
журналом миграций `calendar_schema_migrations`. Время — локальная дата и
минуты от полуночи с шагом 30 минут; интервалы полуоткрытые.

- `domain/CalendarRules.ts` — чистая арифметика дат, проверка слота, рабочего
  окна (`start + duration <= конец дня`), участника и шаблона недели.
- Пересечения записей запрещены; Blocked запрещает записи и не ставится поверх
  записи; Duty — фон и сосуществует с записями.
- Copy/Paste Week — многоразовый шаблон без ID и исходов; существующая запись
  побеждает, пропуски считаются. Clear Week трогает только ещё не начавшиеся
  SCHEDULED-записи и интервалы: прошлое сохраняет исходы и списания.
- `devCalendarClientDeletionParticipant` подключается composition root к
  окончательному удалению клиента (§15.8): будущие записи отменяются, все
  записи теряют связь с клиентом, имя и заметку.

- Учёт занятий подключается через `data/DevAppointmentAccountingHook.ts` в той
  же транзакции; «Записать без списания» хранится в записи и не копируется.

- Исход записи (L02, §48.35) — отдельный от списания аспект: `outcome`
  Завершена/Пропущена/Отменена; закончившаяся SCHEDULED-запись клиента без
  исхода — «Ожидает решения». `AppointmentOutcomeDialog` показывает очередь
  таких записей по одной карточке со стрелками; `correctClient` исправляет
  клиента у начавшейся записи с компенсацией в учёте.

- `CalendarUndoProvider` после «Отменена» 3 секунды предлагает «Вернуть»
  (`restoreCancelled`); «Больше не спрашивать» — `undoCancelPrompt` в настройках.
  Гостевые записи тоже ждут исхода.
- Гость не создаёт карточку клиента; `linkGuestToClient` переносит его записи
  к созданной или существующей карточке (`countSameGuest` — записи с тем же
  именем).

Не реализовано: «Вернуть» после удаления записи в редакторе, управление типами занятий и настройками,
Month Grid, плотная Week/Day timeline и жесты (K02/R09), Share Week.
