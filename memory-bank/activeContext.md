## Правила, которые легко забыть

- Владелец сам проверяет UI на телефоне: без снимков экрана и ADB, правки крупнее и реже (память
  `code-only-no-phone-checks`). Модель — Sonnet по умолчанию; субагенты `Explore`/`reviewer`/`architect`, правила в
  корневом `CLAUDE.md`.
- Реального клиента владельца в программе «П» не трогать; SmokeA/B/C не удалять (группа «Лето» у SmokeC).
- Коммит — `<ID>: что сделано` по-русски; `git push` только по просьбе.
