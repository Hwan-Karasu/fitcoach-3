## Суть

- Android-приложение для персонального тренера: клиенты, календарь, абонементы,
  замеры, анкета, тренировки; позже питание.

  read-only референс внешнего вида и legacy-данных, «в нём много багов».

## Ключевая бизнес-логика

- Календарь, тренировка и Credit Ledger — **независимая семантика**: отмена
  записи не удаляет факт списания, исход записи (`outcome`) решает учёт.
- Структурные правки не уничтожают факты (история, CAS по revision).
- Окончательное удаление клиента идёт через участников-владельцев
  (manifest: owner/tables/count); без участника — fail-closed.
- Опубликованные версии анкеты неизменяемы; ответы хранятся по stable field ID.
- Гость календаря может быть превращён в клиента («гость → клиент»).
